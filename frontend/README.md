# Frontend de Misión Líder París

Aplicación Angular 21 con PrimeNG, Tailwind, SCSS y tokens compartidos. El código está en `src/app/` y los recursos propios en `public/assets/`.

Desde la raíz del repositorio: `npm ci --prefix frontend`, `npm start` y `npm run build`. La aplicación escucha en `http://localhost:4200`.

Consultar [README principal](../README.md), [desarrollo](../docs/development.md) y [contrato de diseño](../docs/design-system.md). No se ejecutan pruebas unitarias durante el incremento vigente por indicación del usuario. `backend/` está reservado para trabajo posterior.
