# Frontend de Misión Líder París

Aplicación Angular 21 con PrimeNG, Tailwind, SCSS y tokens compartidos. El código está en `src/app/` y los recursos propios en `public/assets/`.

Desde la raíz del repositorio: `npm ci --prefix frontend`, `npm start` y `npm run build`. La aplicación escucha en `https://localhost:4200`, con proxy HTTPS de API según [la guía de autenticación](../docs/angular-authentication.md).

Consultar [README principal](../README.md), [desarrollo](../docs/development.md) y [contrato de diseño](../docs/design-system.md). La etapa 2.1 retoma unitarias Angular y E2E contra la API .NET existente en `backend/`.
